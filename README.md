# Gezi Rehberi

Türkiye'nin 81 ilinde gezilecek yerler: harita, canlı konuma göre mesafe, Vikipedi'den fotoğraf ve bilgi, tek dokunuşla Google Maps'te yol tarifi.

- Uygulama: `docs/` (GitHub Pages buradan yayınlanır)
- Yer listesi: `data/yerler-ham.json` (il → [Vikipedi sayfa adı, kategori])
- Kategoriler: t = Tarihi, d = Doğa & Manzara, m = Müze, c = Çarşı & Lezzet, s = Şehir & Semt

Bilgi ve fotoğraflar Vikipedi / Wikimedia Commons (CC BY-SA), harita © OpenStreetMap katkıcıları.
